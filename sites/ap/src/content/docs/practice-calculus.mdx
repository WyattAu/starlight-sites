### Limits

**Intuition:** Limits tell you what value a function approaches as the input gets closer and closer to a target value — even if the function never actually reaches that value.

**Common Mistakes:**
- Confusing the limit value with the function value
- Forgetting to check both left-hand and right-hand limits
- Applying L'Hopital's rule without verifying the indeterminate form
