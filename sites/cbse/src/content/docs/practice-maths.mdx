## Common Mistakes

**Confusing the determinant formula for $2 \times 2$ and $3 \times 3$ matrices:** For a $2 \times 2$ matrix, $\det = ad - bc$. For a $3 \times 3$ matrix, you must use cofactor expansion — there is no simple diagonal formula. Applying the $2 \times 2$ formula to a $3 \times 3$ matrix gives completely wrong answers.

**Forgetting the constant of integration in indefinite integrals:** Every indefinite integral requires $+ C$. This is not optional — without it, the answer is incomplete. For definite integrals, the constant cancels out, but for indefinite integrals (like the CBSE example), omitting $+ C$ costs marks.

**Confusing independent events with mutually exclusive events:** Independent events satisfy $P(A \cap B) = P(A)P(B)$, while mutually exclusive events satisfy $P(A \cap B) = 0$. Mutually exclusive events with non-zero probability are never independent — if one occurs, the other cannot. Using the wrong formula gives incorrect probability calculations.
