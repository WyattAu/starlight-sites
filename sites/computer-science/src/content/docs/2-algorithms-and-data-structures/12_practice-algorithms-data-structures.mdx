## Algorithms and Data Structures -- Practice Problems

## Intuition

**The art of efficient computation:** Algorithm design is like chess strategy — you need to think ahead (plan your approach), recognise patterns (identify the right paradigm), and know when to trade optimality for speed (heuristics vs. exact solutions).

**Why it matters:** The difference between a good and bad algorithm can be the difference between a solution that takes milliseconds and one that takes years. Understanding these concepts lets you make informed choices about code efficiency.

**The key insight:** Comparison-based sorting has a fundamental limit of O(n log n) — no clever algorithm can beat this because of the information-theoretic lower bound. To go faster, you need to use non-comparison methods like radix sort.
