## Intuition

**A global telephone network for computers:** Networking is like a global telephone system — your voice (data) gets converted to signals (packets), routed through switching stations (routers), and reconstructed at the other end. Each layer of the OSI model handles a different part of the conversation.

**Why it matters:** Every internet request — loading a webpage, sending an email, streaming video — involves dozens of networking protocols working together. Understanding them explains why connections are slow, why some sites are blocked, and how security works.

**The key insight:** TCP's reliability comes at a cost — the three-way handshake and acknowledgements add latency, which is why UDP exists for real-time applications where speed matters more than perfect delivery.

## Common Mistakes

**Confusing TCP with UDP:** TCP is reliable and connection-oriented. UDP is fast but unreliable. Don't assume all applications need TCP reliability.

**Forgetting that DNS uses both UDP and TCP:** DNS queries in standard practice use UDP (fast, small). Zone transfers and large responses use TCP. Don't assume DNS always uses UDP.

**Mixing up unicast with multicast:** Unicast is one-to-one. Multicast is one-to-many. Broadcast is one-to-all. Don't confuse the three communication patterns.
