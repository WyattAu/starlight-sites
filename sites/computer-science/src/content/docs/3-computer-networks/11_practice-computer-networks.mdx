## Intuition

**The postal service of the internet:** Networking is like a global postal service — your data gets wrapped in envelopes at each layer (headers), routed through sorting offices (routers), and delivered to the right address. Each layer handles a different part of the journey.

**Why it matters:** Every internet request involves dozens of networking protocols working together. Understanding them explains why connections are slow, how security works, and why some applications need TCP while others use UDP.

**The key insight:** Layered architecture is the key to scalability — each layer can be upgraded independently (IPv4 to IPv6, HTTP/1.1 to HTTP/3) without breaking the layers above or below.

## Common Mistakes

**Confusing stop-and-wait with sliding window:** Stop-and-wait sends one packet and waits for acknowledgement. Sliding window sends multiple packets before waiting. Don't assume all protocols are stop-and-wait.

**Forgetting that TCP uses cumulative acknowledgements:** An ACK for sequence number n acknowledges all bytes up to n-1. Don't assume each packet needs its own ACK.

**Mixing up routing with forwarding:** Routing determines the path. Forwarding moves packets from input to output. They're different network layer functions.
