# Automata and Formal Languages -- Practice Problems

10 MCQ questions covering finite automata, regular expressions, pumping lemma, context-free
grammars, pushdown automata, and Turing machines. Select an option to check your answer.

## Intuition

**Different machines for different puzzles:** Think of automata as a toolkit — a DFA is a simple checklist (can I match this pattern?), a PDA adds a stack of sticky notes (can I count and match?), and a Turing machine gets an infinite scroll (can I compute anything?). Each upgrade unlocks new capabilities but costs more resources.

**Why it matters:** Automata theory is the foundation of compilers, search engines, and protocol design. Knowing which machine can handle a problem tells you whether a solution is even possible — and how efficient it can be.

**The key insight:** The pumping lemma is your lie detector — if a language can't be "pumped" (repeated without breaking the pattern), it's not regular, and no amount of clever DFA design will save it.

## Finite Automata and Regular Languages

<PracticeProblem client:only="solid-js" question={"A DFA is a 5-tuple $M = (Q, \\Sigma, \\delta, q_0, F)$. What distinguishes it from an NFA?&quot; options={[ 'The DFA transition function $\\delta: Q \\times \\Sigma \\to Q$ returns exactly one state; NFA returns a set of states and allows $\\epsilon$-transitions', 'DFAs accept more languages than NFAs', 'NFAs cannot have accepting states', 'DFAs use a stack for computation', ]} correctAnswer={0} explanation=&quot;DFA transitions are deterministic: for each state and symbol, exactly one next state. NFA transitions can return multiple states ($\\delta: Q \\times (\\Sigma \\cup \\{\\epsilon\\}) \\to 2^Q$) and allow $\\epsilon$-transitions (changing state without consuming input). Despite this difference, DFAs and NFAs recognize exactly the same class of languages: the regular languages."} difficulty="easy"  />

<PracticeProblem client:only="solid-js" question={"Converting an NFA with $n$ states to an equivalent DFA using subset construction produces at most how many states?&quot; options={[ '$2^n$ states (each subset of NFA states becomes a DFA state)', '$n^2$ states', '$2n$ states', '$n!$ states', ]} correctAnswer={0} explanation=&quot;The subset construction maps each subset of NFA states to a single DFA state. With $n$ NFA states, there are $2^n$ possible subsets. The worst case requires all $2^n$ DFA states, though in practice many subsets are unreachable. Hopcroft\'s algorithm can then minimize the DFA to the unique minimal equivalent DFA in $O(n \\log n)$ time."} difficulty="medium"  />

<PracticeProblem client:only="solid-js" question={"Using the pumping lemma for regular languages, what string is chosen to prove that $L = \\{a^n b^n : n \\geq 0\\}$ is not regular?&quot; options={[ '$s = a^p b^p$ where $p$ is the pumping length; pumping $y$ (within the first $p$ symbols) breaks the $a$-$b$ balance', &quot;$s = a^p$ (pumping adds more $a$'s)&quot;, '$s = (ab)^p$ (pumping breaks alternation)', &quot;$s = b^p a^p$ (pumping removes $b$'s)&quot;, ]} correctAnswer={0} explanation=&quot;Choose $s = a^p b^p$. Since $|s| \\geq p$ and $|xy| \\leq p$, $y$ consists only of $a$'s: $y = a^k$ for some $k \\geq 1$. Pumping down ($i=0$): $xy^0z = a^{p-k}b^p \\notin L$ since $p-k \\neq p$. This holds for any division of $s = xyz$ satisfying the lemma conditions, so $L$ is not regular."} difficulty="medium"  />

<PracticeProblem client:only="solid-js" question={"Regular languages are closed under which of the following operations?&quot; options={[ 'Union, intersection, complement, concatenation, and Kleene star', 'Union and concatenation only', 'Complement only', 'Intersection and Kleene star only', ]} correctAnswer={0} explanation=&quot;Regular languages are closed under all standard operations: union (parallel NFA construction or $R_1 \\cup R_2$), intersection (product DFA construction), complement (swap accepting/non-accepting states in DFA), concatenation ($R_1 \\cdot R_2$), Kleene star ($R^*$), and reversal. This closure under complement is a key property not shared by context-free languages."} difficulty="easy"  />

## Context-Free Languages and Turing Machines

<PracticeProblem client:only="solid-js" question={"A context-free grammar is ambiguous if some string has two or more different parse trees. Which of the following is inherently ambiguous (has no unambiguous grammar)?&quot; options={[ '$\\{a^i b^j c^k : i = j \\text{ or } j = k\\}$', '$\\{a^n b^n : n \\geq 0\\}$', '$\\{ww^R : w \\in \\{a,b\\}^*\\}$', 'The language of balanced parentheses', ]} correctAnswer={0} explanation=&quot;$\\{a^i b^j c^k : i = j \\text{ or } j = k\\}$ is inherently ambiguous: strings where $i = j = k$ (e.g., $a^n b^n c^n$) can be derived through the $i=j$ branch or the $j=k$ branch, and no unambiguous grammar exists for this union. The language $\\{a^n b^n\\}$ has an unambiguous CFG ($S \\to aSb \\mid \\epsilon$)."} difficulty="hard"  />

<PracticeProblem client:only="solid-js" question={"Which of the following is NOT closed under for context-free languages?&quot; options={[ 'Intersection and complement', 'Union, concatenation, and Kleene star', 'Intersection with a regular language', 'Union and Kleene star', ]} correctAnswer={0} explanation=&quot;CFLs are closed under union, concatenation, Kleene star, and intersection with a regular language (product of PDA and DFA). However, CFLs are NOT closed under intersection ($L_1 \\cap L_2$ of two CFLs may not be context-free) or complement. This is a key distinction from regular languages, which are closed under both."} difficulty="medium"  />

<PracticeProblem client:only="solid-js" question={"The pumping lemma for context-free languages states that if $L$ is a CFL, any string $s \\in L$ with $|s| \\geq p$ can be divided as $s = uvxyz$ with $|vxy| \\leq p$. How is this used to prove $L = \\{a^n b^n c^n : n \\geq 0\\}$ is not context-free?&quot; options={[ 'Since $|vxy| \\leq p$, the substring $vxy$ cannot span all three letter types; pumping breaks the balance', 'Choose $s = a^p b^p c^p$ and show that removing $v$ and $y$ preserves the balance', 'Show that the language is regular instead', 'Apply the regular pumping lemma', ]} correctAnswer={0} explanation=&quot;Choose $s = a^p b^p c^p$. Since $|vxy| \\leq p$, the pumped substring $vxy$ can contain at most two of the three letter types. If it contains only $a$'s: pumping increases $a$ count but not $b$ or $c$. If it spans $a$'s and $b$'s: pumping changes $a$ and $b$ counts but not $c$. In all cases, the $a^n b^n c^n$ structure is broken."} difficulty="hard"  />

<PracticeProblem client:only="solid-js" question={"What does Rice\'s theorem state about non-trivial properties of Turing machine languages?&quot; options={[ 'Any non-trivial property of the language recognized by a TM is undecidable', 'Any property of a TM\'s code is decidable', 'All properties of TM languages are decidable', 'Only properties related to the halting problem are undecidable', ]} correctAnswer={0} explanation=&quot;Rice\'s theorem: if $P$ is a non-trivial property of TM languages (holds for some TMs, not for others, and depends only on the language, not the machine), then $P$ is undecidable. Examples: &quot;Is $L(M)$ finite?&quot;, &quot;Is $L(M) = \\Sigma^*$?&quot;, &quot;Is $L(M)$ regular?&quot; are all undecidable. Properties of the machine\'s computation (not its language) may still be decidable."} difficulty="medium"  />

<PracticeProblem client:only="solid-js" question={"A Pushdown Automaton (PDA) uses a stack as auxiliary memory. What is the relationship between deterministic PDAs (DPDA) and nondeterministic PDAs (NPDA)?&quot; options={[ 'DPDAs are strictly less powerful than NPDAs; NPDAs = CFLs, DPDAs = proper subset', 'DPDAs and NPDAs recognize the same languages', 'DPDAs are more powerful than NPDAs', 'DPDAs can recognize all CFLs but NPDAs can recognize more', ]} correctAnswer={0} explanation=&quot;Unlike finite automata (where DFA = NFA), deterministic and nondeterministic PDAs differ in power. NPDAs recognize exactly the context-free languages. DPDAs recognize a proper subset (deterministic CFLs). Languages like $\\{ww^R : w \\in \\{a,b\\}^*\\}$ are CFLs recognizable by NPDAs but not by DPDAs."} difficulty="hard"  />

<PracticeProblem client:only="solid-js" question={"Which of the following correctly describes the language classes Decidable, Turing-Recognizable (RE), and All Languages?&quot; options={[ 'Decidable $\\subsetneq$ RE $\\subsetneq$ All Languages', 'Decidable = RE = All Languages', 'RE $\\subsetneq$ Decidable $\\subsetneq$ All Languages', 'Decidable $\\subsetneq$ All Languages $\\subsetneq$ RE', ]} correctAnswer={0} explanation=&quot;Decidable languages are recognized by TMs that halt on all inputs (accept members, reject non-members). Turing-recognizable (recursively enumerable) languages are recognized by TMs that accept members but may loop on non-members. There exist languages that are not even RE (e.g., the complement of the halting problem). The halting problem itself is RE but not decidable."} difficulty="medium"  />

## Additional Automata and Formal Languages Questions

<PracticeProblem client:only="solid-js" question={"A deterministic pushdown automaton (DPDA) cannot recognise which of the following languages, even though it is context-free?&quot; options={[ '$\\{ww^R : w \\in \\{a,b\\}^*\\}$ (palindromes of even length)', '$\\{a^n b^n : n \\geq 0\\}$', '$\\{a^n b^m : n \\neq m\\}$', '$\\{a^n b^n c^m : n,m \\geq 0\\}$', ]} correctAnswer={0} explanation=&quot;$\\{ww^R\\}$ is a context-free language recognised by an NPDA but not by any DPDA. The NPDA can nondeterministically guess the midpoint of the string and then verify the second half is the reverse of the first. DPDAs cannot make this guess because they must commit to a single computation path. DPDAs recognise a proper subset of the CFLs known as deterministic CFLs."} difficulty="hard"  />

<PracticeProblem client:only="solid-js" question={"In Myhill--Nerode theorem, what does the number of equivalence classes of a language $L$ over $\\Sigma^*$ directly correspond to?&quot; options={[ 'The number of states in the minimal DFA recognising $L$', 'The number of productions in the minimal CFG for $L$', 'The number of states in the minimal NFA for $L$', 'The length of the shortest string not in $L$', ]} correctAnswer={0} explanation=&quot;The Myhill--Nerode theorem establishes a bijection: the number of equivalence classes of the relation $x \\sim_L y$ iff $\\forall z: xz \\in L \\Leftrightarrow yz \\in L$ equals the number of states in the unique minimal DFA for $L$. If this number is finite, $L$ is regular. The theorem also provides a minimisation algorithm: two states in the same DFA are equivalent iff they are not distinguishable by any suffix."} difficulty="hard"  />

<PracticeProblem client:only="solid-js" question={"What is the significance of the closure properties of regular languages under complementation?&quot; options={[ 'It allows proving non-regularity by contradiction: if the complement were regular, the original language would also be regular', 'It proves that regular languages are closed under all computable operations', 'It means regular languages cannot be complemented', 'It only applies to deterministic finite automata', ]} correctAnswer={0} explanation=&quot;Since regular languages are closed under complementation (swap accepting and non-accepting states in a DFA), if a language $L$ is regular then $\\overline{L}$ is also regular. Contrapositively, if $\\overline{L}$ is not regular, then $L$ is not regular either. This closure property is useful in proving non-regularity when direct application of the pumping lemma is difficult."} difficulty="medium"  />

<PracticeProblem client:only="solid-js" question={"What class of languages is recognised by a linear bounded automaton (LBA)?&quot; options={[ 'Context-sensitive languages (CSL)', 'Context-free languages', 'Regular languages', 'Recursively enumerable languages', ]} correctAnswer={0} explanation=&quot;An LBA is a Turing machine whose tape head is confined to the portion of the tape containing the input. It recognises exactly the context-sensitive languages, which are those generated by context-sensitive grammars (in Kuroda normal form). CSLs strictly contain the context-free languages. The emptiness problem for LBAs is decidable, unlike for general TMs, but the membership problem is PSPACE-complete."} difficulty="medium"  />

<PracticeProblem client:only="solid-js" question={"In the construction of a PDA from a context-free grammar in Chomsky normal form, what role does the stack play?&quot; options={[ 'It simulates the leftmost derivation by pushing nonterminals and replacing them with the right-hand side of productions', 'It stores the input string for comparison', 'It counts the number of steps in the derivation', 'It reverses the input string to check for palindromes', ]} correctAnswer={0} explanation=&quot;The PDA starts with the start symbol on the stack. At each step, it examines the top of stack (a nonterminal $A$) and the current input symbol. If a production $A \\to \\alpha$ matches, it pops $A$ and pushes the symbols of $\\alpha$ (rightmost first for leftmost derivation). In CNF, each production has at most two symbols, so the stack grows by at most one symbol per step. Acceptance is by empty stack."} difficulty="hard"  />
