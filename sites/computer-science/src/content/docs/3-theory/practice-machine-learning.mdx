## Intuition

**Learning from examples like a child:** Machine learning is like teaching a child to recognise cats — you show thousands of examples, they gradually learn the pattern, and eventually they can spot cats they've never seen. The algorithm finds patterns in data that humans might miss.

**Why it matters:** ML powers recommendation systems, medical diagnosis, autonomous vehicles, and language models. Understanding it explains why some models overfit, why more data in most cases helps, and how bias enters automated decisions.

**The key insight:** All models are wrong, but some are useful — the goal isn't perfection but finding the right balance between memorising training data (overfitting) and missing real patterns (underfitting).
