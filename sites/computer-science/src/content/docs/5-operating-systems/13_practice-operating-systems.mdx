## Intuition

**The conductor of the hardware orchestra:** The OS is like a conductor — it coordinates the CPU (violins), memory (percussion), and I/O devices (brass), making sure they all play in harmony. Without it, every process would fight for resources and nothing would work.

**Why it matters:** Understanding OS concepts explains why your computer slows down with too many tabs, how virtual memory extends your RAM, and why processes can't just access any memory address they want.

**The key insight:** Scheduling algorithms reveal a fundamental tension — SJF minimises average waiting time but requires knowing the future (burst times), while RR is fair but adds context-switching overhead. Real systems use hybrid approaches like MLFQ.

## Common Mistakes

**Confusing internal with external fragmentation:** Internal fragmentation is wasted space within allocated blocks. External fragmentation is wasted space between allocated blocks. Don't use them interchangeably.

**Assuming more frames always reduces page faults:** Belady's anomaly shows that with FIFO, more frames can increase page faults. LRU and Optimal don't have this problem.

**Mixing up virtual memory with virtual machines:** Virtual memory is an OS technique for using disk as extended RAM. Virtual machines are emulated computers. They're different concepts.
