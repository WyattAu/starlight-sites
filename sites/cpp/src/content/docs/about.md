## About Wyatt's Notes — C++

Wyatt's Notes provides thorough study materials for C++ programming. These notes cover the language from modern C++17/20 features through templates, move semantics, and systems-level programming, building the expertise needed for performance-critical software development.

### Why Trust These Resources?

These notes are developed by **Wyatt**, an educator and content creator with deep expertise in C++ and systems programming. Content follows a progressive structure from language fundamentals through advanced metaprogramming, reflecting how C++ is taught and used professionally.

Materials emphasise the RAII principle, template metaprogramming, and the zero-cost abstractions that define modern C++. Every concept includes practical examples and explains the performance implications that matter in production systems.

### What You'll Find

- **Modern C++** covering C++17/20 features and idioms
- **Templates and metaprogramming** for generic and compile-time programming
- **Memory management** with smart pointers, move semantics, and RAII
- **Standard Library** covering STL containers, algorithms, and iterators
- **Concurrency** with threads, atomics, and lock-free programming

### Credentials

Wyatt develops resources across C++, systems programming, and computer science theory, providing the depth that serious C++ programmers need. Materials are informed by the ISO C++ standard, expert-level references, and production codebase analysis.
