### Practice Problem Tips

- **Rationalise denominators**: multiply numerator and denominator by the conjugate. For 1/(√3 - 1), multiply by (√3 + 1)/(√3 + 1) to get (√3 + 1)/2.
- **Check domain before solving**: for logarithmic equations, ensure all arguments are positive. For square root equations, ensure the radicand is non-negative.
- **Verify solutions**: substitute answers back into the original equation, especially when squaring both sides (which can introduce extraneous solutions).

### Approach Strategy

- For quadratic equations, first check if factorisation is possible before using the formula.
- For simultaneous equations, decide whether substitution or elimination is more efficient based on the structure.
- For trigonometry, sketch the angle in the correct quadrant to determine the sign of the trig ratio.

## Intuition

Approach each problem by first classifying it: is this an equation to solve, a function to analyse, or a geometric relationship? Then select the appropriate technique from your toolkit.

## Common Mistakes

- **Incorrect sign when completing the square**: (x + 3)² = x² + 6x + 9, not x² + 6x + 3. The constant term is (b/2)².
- **Forgetting ± in square roots**: √(x²) = |x|, not just x. If x² = 9, then x = ±3.
- **Confusing arithmetic and geometric sequences**: arithmetic has common difference d, geometric has common ratio r. Mixing formulas gives wrong nth terms.
