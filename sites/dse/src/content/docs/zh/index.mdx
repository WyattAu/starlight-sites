## Common Mistakes

**Assuming language affects concept difficulty:** Technical concepts are universal. The language of instruction doesn't change the underlying physics, chemistry, or biology.

**Not using both English and Chinese resources:** Some concepts are better explained in one language. Use both to deepen understanding.

**Forgetting that DSE exams are in English:** Even if you study in Chinese, practice answering in English to prepare for the actual exam format.
