# Organic

高考 chemistry 学习笔记 - Organic

## 核心概念

### 烃

**烷烃：** 通式 $C_nH_{2n+2}$，代表物甲烷 $\text{CH}_4$（正四面体结构，键角 $109°28'$）

**烯烃：** 通式 $C_nH_{2n}$，代表物乙烯 $\text{CH}_2=\text{CH}_2$（平面结构，含碳碳双键）

**炔烃：** 通式 $C_nH_{2n-2}$，代表物乙炔 $\text{CH} \equiv \text{CH}$（直线型结构）

**苯：** 分子式 $\text{C}_6\text{H}_6$，平面正六边形结构，碳碳键介于单键和双键之间。

### 烃的衍生物

**醇：** 通式 $R-\text{OH}$，乙醇 $\text{CH}_3\text{CH}_2\text{OH}$

**醛：** 通式 $R-\text{CHO}$，乙醛 $\text{CH}_3\text{CHO}$

**羧酸：** 通式 $R-\text{COOH}$，乙酸 $\text{CH}_3\text{COOH}$

**酯：** 通式 $R-\text{COOR}'$，乙酸乙酯 $\text{CH}_3\text{COOCH}_2\text{CH}_3$

### 重要反应类型

**取代反应：** 有机分子中的原子或原子团被其他原子或原子团替代。

**加成反应：** 有机分子中的不饱和键（双键或三键）两端各加上一个原子或原子团。

**消去反应：** 有机化合物在一定条件下脱去小分子（如 $\text{H}_2\text{O}$、$\text{HBr}$）生成不饱和化合物。

**酯化反应：** 酸和醇反应生成酯和水，属于取代反应。

### 同分异构体

**碳链异构：** 碳骨架不同，如正丁烷和异丁烷。

**位置异构：** 官能团位置不同，如1-丙醇和2-丙醇。

**官能团异构：** 官能团种类不同，如乙醇和二甲醚。

## 典型例题

### 例题1：有机推断

**题目：** 分子式为 $C_4H_8O_2$ 的有机物，能与 $\text{NaOH}$ 溶液反应，可能的结构简式有哪些？

**解答：**

步骤1：$C_4H_8O_2$ 的不饱和度 $\Omega = 4 + 1 - \frac{8}{2} = 1$，含一个双键

步骤2：能与 $\text{NaOH}$ 反应，说明含有酯基 $-\text{COO}-$ 或羧基 $-\text{COOH}$

步骤3：分析可能的酯类结构：
- $\text{HCOOCH}_2\text{CH}_2\text{CH}_3$（甲酸丙酯）
- $\text{HCOOCH(CH}_3)_2$（甲酸异丙酯）
- $\text{CH}_3\text{COOCH}_2\text{CH}_3$（乙酸乙酯）
- $\text{CH}_3\text{CH}_2\text{COOCH}_3$（丙酸甲酯）

步骤4：羧酸类结构：
- $\text{CH}_3\text{CH}_2\text{CH}_2\text{COOH}$（丁酸）
- $(\text{CH}_3)_2\text{CHCOOH}$（2-甲基丙酸）

**答案：** 共 $6$ 种结构

### 例题2：酯化反应

**题目：** 以乙烯为原料，设计合成乙酸乙酯的路线。

**解答：**

步骤1：乙烯水化制乙醇：
$$\text{CH}_2=\text{CH}_2 + \text{H}_2\text{O} \xrightarrow{\text{催化剂}} \text{CH}_3\text{CH}_2\text{OH}$$

步骤2：乙醇氧化制乙醛：
$$2\text{CH}_3\text{CH}_2\text{OH} + \text{O}_2 \xrightarrow{\text{Cu/Ag, }\Delta} 2\text{CH}_3\text{CHO} + 2\text{H}_2\text{O}$$

步骤3：乙醛氧化制乙酸：
$$2\text{CH}_3\text{CHO} + \text{O}_2 \xrightarrow{\text{催化剂}} 2\text{CH}_3\text{COOH}$$

步骤4：乙醇与乙酸酯化：
$$\text{CH}_3\text{COOH} + \text{CH}_3\text{CH}_2\text{OH} \xrightleftharpoons[\Delta]{\text{浓H}_2\text{SO}_4} \text{CH}_3\text{COOCH}_2\text{CH}_3 + \text{H}_2\text{O}$$

**答案：** 乙烯 $\rightarrow$ 乙醇 $\rightarrow$ 乙醛 $\rightarrow$ 乙酸 $\rightarrow$ 乙酸乙酯

### 例题3：同分异构体

**题目：** 写出分子式为 $C_5H_{12}$ 的所有同分异构体的结构简式。

**解答：**

步骤1：$C_5H_{12}$ 为饱和烷烃，不饱和度为 $0$

步骤2：碳链异构分析：
- 直链：$\text{CH}_3\text{CH}_2\text{CH}_2\text{CH}_2\text{CH}_3$（正戊烷）
- 主链 $4$ 个碳：$\text{CH}_3\text{CH(CH}_3)\text{CH}_2\text{CH}_3$（异戊烷）
- 主链 $3$ 个碳：$\text{C(CH}_3)_4$（新戊烷）

**答案：** 共 $3$ 种同分异构体

## 考试技巧

1. 有机推断题中，先计算不饱和度判断官能团类型
2. 同分异构体计数时，按碳链异构 $\rightarrow$ 位置异构 $\rightarrow$ 官能团异构的顺序
3. 酯化反应中浓硫酸的作用：催化剂和吸水剂
4. 检验醛基用银氨溶液或新制 $\text{Cu(OH)}_2$ 悬浊液
