# Optics

高考 physics 学习笔记 - Optics

## 核心概念

### 光的直线传播

**光速：** 真空中 $c = 3 \times 10^8\,\text{m/s}$

**影的形成：** 光沿直线传播遇到不透明物体，在物体后面形成阴影区域。

**全反射：** 光从光密介质射向光疏介质时，当入射角大于临界角时，光线全部被反射回光密介质。

临界角公式：$\sin C = \frac{1}{n}$（$n$ 为折射率）

### 光的反射

**反射定律：** 反射角等于入射角，反射光线、入射光线和法线在同一平面内。

**平面镜成像特点：**
- 像与物关于镜面对称
- 像是虚像
- 像与物等大

### 光的折射

**折射定律（Snell 定律）：** $n_1 \sin\theta_1 = n_2 \sin\theta_2$

**折射率：** $n = \frac{c}{v}$（$v$ 为光在介质中的速度）

**全反射条件：**
1. 光从光密介质射向光疏介质
2. 入射角大于或等于临界角

### 光的干涉和衍射

**双缝干涉：** 明纹位置 $x = k \cdot \frac{L\lambda}{d}$（$k = 0, \pm 1, \pm 2, \ldots$）

**薄膜干涉：** 光在薄膜前后两个表面反射的光叠加产生干涉。

**单缝衍射：** 中央明纹最宽最亮，两侧明纹逐渐变暗变窄。

### 光电效应

**爱因斯坦光电效应方程：** $E_k = h\nu - W_0$

其中 $h\nu$ 为光子能量，$W_0$ 为逸出功，$E_k$ 为光电子的最大初动能。

**截止频率：** $\nu_0 = \frac{W_0}{h}$

## 典型例题

### 例题1：折射定律

**题目：** 一束光从空气射入水中，入射角为 $45°$，水的折射率 $n = \frac{4}{3}$，求折射角。

**解答：**

步骤1：由折射定律 $n_1 \sin\theta_1 = n_2 \sin\theta_2$

步骤2：代入数据（空气 $n_1 \approx 1$）：
$$\sin 45° = \frac{4}{3} \sin\theta_2$$
$$\frac{\sqrt{2}}{2} = \frac{4}{3} \sin\theta_2$$

步骤3：解得：
$$\sin\theta_2 = \frac{3\sqrt{2}}{8}$$
$$\theta_2 = \arcsin\frac{3\sqrt{2}}{8}$$

**答案：** 折射角为 $\arcsin\frac{3\sqrt{2}}{8}$

### 例题2：全反射

**题目：** 光从玻璃（$n = 1.5$）射向空气，求全反射的临界角。

**解答：**

步骤1：由全反射临界角公式 $\sin C = \frac{1}{n}$

步骤2：代入数据：
$$\sin C = \frac{1}{1.5} = \frac{2}{3}$$

步骤3：计算临界角：
$$C = \arcsin\frac{2}{3} \approx 41.8°$$

**答案：** 临界角约为 $41.8°$

### 例题3：光电效应

**题目：** 用频率为 $\nu = 6 \times 10^{14}\,\text{Hz}$ 的光照射某金属，逸出功 $W_0 = 2.0\,\text{eV}$，求光电子的最大初动能（$h = 6.63 \times 10^{-34}\,\text{J·s}$，$1\,\text{eV} = 1.6 \times 10^{-19}\,\text{J}$）。

**解答：**

步骤1：计算光子能量：
$$E = h\nu = 6.63 \times 10^{-34} \times 6 \times 10^{14} = 3.98 \times 10^{-19}\,\text{J}$$

步骤2：换算为电子伏特：
$$E = \frac{3.98 \times 10^{-19}}{1.6 \times 10^{-19}} \approx 2.49\,\text{eV}$$

步骤3：由光电效应方程：
$$E_k = E - W_0 = 2.49 - 2.0 = 0.49\,\text{eV}$$

**答案：** 光电子的最大初动能约为 $0.49\,\text{eV}$

## 考试技巧

1. 光路可逆原理在折射和反射问题中经常用到
2. 全反射问题必须先判断光是否从光密介质射向光疏介质
3. 干涉问题注意区分明纹和暗纹的条件
4. 光电效应问题中，光强影响光电流大小，频率影响光电子的最大初动能

## 练习题

1. 一束光从水（$n = \frac{4}{3}$）射入空气，入射角为 $30°$，求折射角
2. 求光从玻璃（$n = 1.5$）射入水（$n = \frac{4}{3}$）时的临界角
3. 用波长为 $400\,\text{nm}$ 的光照射某金属，逸出功为 $2.5\,\text{eV}$，求光电子的最大初动能

### 例题4：双缝干涉

**题目：** 在双缝干涉实验中，双缝间距为 $0.2\,\text{mm}$，缝到屏幕的距离为 $1\,\text{m}$，所用光的波长为 $600\,\text{nm}$。求相邻明纹之间的距离。

**解答：**

步骤1：由双缝干涉公式，相邻明纹间距：
$$\Delta x = \frac{L\lambda}{d}$$

步骤2：代入数据：
$$\Delta x = \frac{1 \times 600 \times 10^{-9}}{0.2 \times 10^{-3}} = \frac{6 \times 10^{-7}}{2 \times 10^{-4}} = 3 \times 10^{-3}\,\text{m} = 3\,\text{mm}$$

**答案：** 相邻明纹间距为 $3\,\text{mm}$

### 例题5：光的折射与全反射

**题目：** 一束光从空气射入玻璃砖（$n = 1.5$），入射角为 $45°$。光线穿过玻璃砖后，出射光线与入射光线的侧移量是多少？（玻璃砖厚度为 $10\,\text{cm}$）

**解答：**

步骤1：由折射定律求折射角：
$$\sin 45° = 1.5 \sin r \implies \sin r = \frac{\sqrt{2}/2}{1.5} = \frac{\sqrt{2}}{3}$$
$$r \approx 28.1°$$

步骤2：在玻璃砖内的水平位移：
$$x = d \tan r = 10 \times \tan 28.1° \approx 10 \times 0.534 = 5.34\,\text{cm}$$

步骤3：侧移量（入射光线延长线与出射光线的垂直距离）：
$$\delta = d \sin(i - r) / \cos r = 10 \times \sin(45° - 28.1°) / \cos 28.1°$$
$$= 10 \times \sin 16.9° / \cos 28.1° \approx 10 \times 0.291 / 0.882 = 3.3\,\text{cm}$$

**答案：** 侧移量约为 $3.3\,\text{cm}$

### 例题6：光电效应综合

**题目：** 用频率为 $\nu_1$ 的光照射某金属，光电子的最大初动能为 $E_{k1}$；用频率为 $\nu_2$ 的光照射，最大初动能为 $E_{k2}$。求该金属的逸出功和普朗克常量。

**解答：**

步骤1：由光电效应方程：
$$E_{k1} = h\nu_1 - W_0$$
$$E_{k2} = h\nu_2 - W_0$$

步骤2：两式相减：
$$E_{k1} - E_{k2} = h(\nu_1 - \nu_2)$$

步骤3：解得普朗克常量：
$$h = \frac{E_{k1} - E_{k2}}{\nu_1 - \nu_2}$$

步骤4：代入第一个方程求逸出功：
$$W_0 = h\nu_1 - E_{k1} = \frac{(E_{k1} - E_{k2})\nu_1}{\nu_1 - \nu_2} - E_{k1}$$
$$= \frac{E_{k1}\nu_1 - E_{k2}\nu_1 - E_{k1}\nu_1 + E_{k1}\nu_2}{\nu_1 - \nu_2} = \frac{E_{k1}\nu_2 - E_{k2}\nu_1}{\nu_1 - \nu_2}$$

**答案：** $h = \dfrac{E_{k1} - E_{k2}}{\nu_1 - \nu_2}$，$W_0 = \dfrac{E_{k1}\nu_2 - E_{k2}\nu_1}{\nu_1 - \nu_2}$

## 深入理解

### 光学问题的解题思路

1. **折射问题：** 先画光路图，确定入射角和折射角，再用折射定律
2. **全反射问题：** 先判断是否从光密介质射向光疏介质，再计算临界角
3. **干涉问题：** 区分双缝干涉（$\Delta x = L\lambda/d$）和薄膜干涉（光程差分析）
4. **光电效应：** 理解截止频率、最大初动能与频率的线性关系

### 光路可逆原理

在几何光学中，光路是可逆的。如果光线从A到B经过某光学系统，那么从B发出的光线将沿原路返回A。这个原理在解题中非常有用，可以简化复杂光路的分析。

## 更多典型例题

### 例题7：光的折射与棱镜

**题目：** 一束光以入射角 $i = 60°$ 射入顶角为 $A = 60°$ 的等边三棱镜的一个侧面，从另一侧面射出。已知棱镜的折射率 $n = \sqrt{3}$，求光线的偏向角。

**解答：**

步骤1：在第一个界面，由折射定律：
$$\sin 60° = \sqrt{3} \sin r_1$$
$$\frac{\sqrt{3}}{2} = \sqrt{3} \sin r_1 \implies \sin r_1 = \frac{1}{2} \implies r_1 = 30°$$

步骤2：由棱镜的几何关系，$r_1 + r_2 = A$：
$$r_2 = A - r_1 = 60° - 30° = 30°$$

步骤3：在第二个界面，由折射定律：
$$\sqrt{3} \sin r_2 = \sin e$$
$$\sqrt{3} \sin 30° = \sin e$$
$$\frac{\sqrt{3}}{2} = \sin e \implies e = 60°$$

步骤4：偏向角：
$$\delta = i + e - A = 60° + 60° - 60° = 60°$$

**答案：** 光线的偏向角为 $60°$

**考试技巧：** 三棱镜问题中，光线通过棱镜时向底面偏折。最小偏向角条件为 $r_1 = r_2 = A/2$，此时 $i = e$。

### 例题8：光电效应的实验规律

**题目：** 用两种频率分别为 $\nu_1$ 和 $\nu_2$（$\nu_1 > \nu_2$）的光照射同一金属，测得遏止电压分别为 $U_1$ 和 $U_2$。求该金属的逸出功和普朗克常量。

**解答：**

步骤1：由光电效应方程和遏止电压的关系：
$$eU_1 = h\nu_1 - W_0$$
$$eU_2 = h\nu_2 - W_0$$

步骤2：两式相减：
$$e(U_1 - U_2) = h(\nu_1 - \nu_2)$$

步骤3：解得普朗克常量：
$$h = \frac{e(U_1 - U_2)}{\nu_1 - \nu_2}$$

步骤4：代入第一个方程求逸出功：
$$W_0 = h\nu_1 - eU_1 = \frac{e(U_1 - U_2)\nu_1}{\nu_1 - \nu_2} - eU_1$$
$$= \frac{e\nu_1 U_1 - e\nu_1 U_2 - eU_1 \nu_1 + eU_1 \nu_2}{\nu_1 - \nu_2} = \frac{e(U_1 \nu_2 - U_2 \nu_1)}{\nu_1 - \nu_2}$$

**答案：** $h = \dfrac{e(U_1 - U_2)}{\nu_1 - \nu_2}$，$W_0 = \dfrac{e(U_1 \nu_2 - U_2 \nu_1)}{\nu_1 - \nu_2}$

**常见错误：** 遏止电压对应的是光电子的最大初动能，即 $eU_c = E_k$。不同频率的光照射同一金属，逸出功相同。

### 例题9：光的干涉条纹计算

**题目：** 在双缝干涉实验中，用波长为 $\lambda = 500\,\text{nm}$ 的绿光照射双缝，测得相邻明纹间距为 $\Delta x = 2\,\text{mm}$。若改用波长为 $\lambda' = 700\,\text{nm}$ 的红光照射，其他条件不变，相邻明纹间距变为多少？

**解答：**

步骤1：由双缝干涉公式 $\Delta x = \dfrac{L\lambda}{d}$，可知 $\Delta x \propto \lambda$。

步骤2：因此：
$$\frac{\Delta x'}{\Delta x} = \frac{\lambda'}{\lambda}$$

步骤3：代入数据：
$$\Delta x' = \Delta x \cdot \frac{\lambda'}{\lambda} = 2 \times \frac{700}{500} = 2.8\,\text{mm}$$

**答案：** 相邻明纹间距变为 $2.8\,\text{mm}$

**考试技巧：** 双缝干涉中，波长越长，条纹间距越大。红光条纹间距大于绿光，绿光大于蓝光。条纹间距与波长成正比。

### 例题10：光的全反射应用

**题目：** 光纤由折射率为 $n_1 = 1.5$ 的纤芯和折射率为 $n_2 = 1.3$ 的包层构成。求光在纤芯中传播时，入射角必须满足什么条件才能发生全反射？

**解答：**

步骤1：全反射条件：光从光密介质射向光疏介质，入射角大于临界角

步骤2：临界角 $C$ 满足：$\sin C = \dfrac{n_2}{n_1} = \dfrac{1.3}{1.5} = \dfrac{13}{15}$

步骤3：故 $C = \arcsin\dfrac{13}{15} \approx 60.1°$

步骤4：光在纤芯中传播时，入射角 $\theta$ 必须满足 $\theta > C \approx 60.1°$

**答案：** 入射角必须大于 $\arcsin\dfrac{13}{15} \approx 60.1°$

**考试技巧：** 光纤通信利用全反射原理，光在纤芯中不断全反射向前传播。数值孔径 $NA = \sqrt{n_1^2 - n_2^2}$ 决定了光纤的集光能力。

### 例题11：光电效应的遏止电压

**题目：** 用频率为 $\nu = 6 \times 10^{14}\,\text{Hz}$ 的光照射某金属，测得遏止电压为 $U_c = 0.5\,\text{V}$。求该金属的逸出功和截止频率（$e = 1.6 \times 10^{-19}\,\text{C}$，$h = 6.63 \times 10^{-34}\,\text{J·s}$）。

**解答：**

步骤1：由光电效应方程：$E_k = h\nu - W_0$

步骤2：遏止电压与最大初动能的关系：$eU_c = E_k$

步骤3：$E_k = 1.6 \times 10^{-19} \times 0.5 = 8 \times 10^{-20}\,\text{J}$

步骤4：$W_0 = h\nu - E_k = 6.63 \times 10^{-34} \times 6 \times 10^{14} - 8 \times 10^{-20} = 3.98 \times 10^{-19} - 8 \times 10^{-20} = 3.18 \times 10^{-19}\,\text{J}$

步骤5：$W_0 = \dfrac{3.18 \times 10^{-19}}{1.6 \times 10^{-19}} \approx 1.99\,\text{eV}$

步骤6：截止频率 $\nu_0 = \dfrac{W_0}{h} = \dfrac{3.18 \times 10^{-19}}{6.63 \times 10^{-34}} \approx 4.8 \times 10^{14}\,\text{Hz}$

**答案：** 逸出功约为 $1.99\,\text{eV}$，截止频率约为 $4.8 \times 10^{14}\,\text{Hz}$

**常见错误：** 遏止电压对应的是光电子的最大初动能，不是光子能量。$eU_c = E_k = h\nu - W_0$。

### 例题12：光的偏振

**题目：** 自然光通过两个偏振片后，光强变为原来的 $\dfrac{1}{8}$。若第一个偏振片固定，第二个偏振片旋转 $90°$，求旋转后的光强。

**解答：**

步骤1：自然光通过第一个偏振片后，光强变为 $\dfrac{I_0}{2}$

步骤2：通过第二个偏振片后，由马吕斯定律：$I = \dfrac{I_0}{2}\cos^2\theta$

步骤3：初始时 $I = \dfrac{I_0}{8}$，故 $\dfrac{I_0}{2}\cos^2\theta = \dfrac{I_0}{8}$，$\cos^2\theta = \dfrac{1}{4}$，$\cos\theta = \dfrac{1}{2}$，$\theta = 60°$

步骤4：旋转 $90°$ 后，夹角变为 $60° + 90° = 150°$ 或 $|60° - 90°| = 30°$

步骤5：若夹角为 $30°$：$I' = \dfrac{I_0}{2}\cos^2 30° = \dfrac{I_0}{2} \times \dfrac{3}{4} = \dfrac{3I_0}{8}$

步骤6：若夹角为 $150°$：$I' = \dfrac{I_0}{2}\cos^2 150° = \dfrac{I_0}{2} \times \dfrac{3}{4} = \dfrac{3I_0}{8}$

**答案：** 旋转后的光强为 $\dfrac{3I_0}{8}$

**考试技巧：** 马吕斯定律：$I = I_0 \cos^2\theta$，其中 $\theta$ 是两偏振片透振方向的夹角。
