## 代数与函数

<PracticeProblem client:only="solid-js" question={"已知集合 $A = \\{x \\mid x^2 - 3x + 2 = 0\\}$，$B = \\{x \\mid x^2 - x = 0\\}$，则 $A \\cap B$ 等于:"} options={['$\\{0, 1, 2\\}$', '$\\{1\\}$', '$\\{0, 2\\}$', '$\\emptyset$']} correctAnswer={1} explanation="解方程 $x^2 - 3x + 2 = 0$ 得 $x = 1$ 或 $x = 2$，故 $A = \\{1, 2\\}$。解方程 $x^2 - x = 0$ 得 $x = 0$ 或 $x = 1$，故 $B = \\{0, 1\\}$。$A \\cap B = \\{1\\}$。" difficulty="easy"  />

<PracticeProblem client:only="solid-js" question={"函数 $f(x) = \\dfrac{1}{\\sqrt{x-1}}$ 的定义域为:"} options={['$(1, +\\infty)$', '$[1, +\\infty)$', '$(-\\infty, 1)$', '$\\mathbb{R} \\setminus \\{1\\}$']} correctAnswer={0} explanation="分母不能为零且根号内必须大于零，即 $x - 1 > 0$，解得 $x > 1$。定义域为 $(1, +\\infty)$。" difficulty="easy"  />

<PracticeProblem client:only="solid-js" question={"若 $\\log_2 a + \\log_2 (a-1) = 1$，则 $a$ 的值为:"} options={['$2$', '$-1$', '$2$ 或 $-1$', '无解']} correctAnswer={0} explanation="由对数运算法则：$\\log_2 [a(a-1)] = 1$，故 $a(a-1) = 2$，即 $a^2 - a - 2 = 0$，解得 $a = 2$ 或 $a = -1$。由于 $a > 0$ 且 $a - 1 > 0$，故 $a > 1$，所以 $a = 2$。" difficulty="medium"  />

## 函数性质

<PracticeProblem client:only="solid-js" question={"函数 $f(x) = x^3 - 3x$ 的单调递增区间为:"} options={['$(-1, 1)$', '$(-\\infty, -1)$ 和 $(1, +\\infty)$', '$(-\\infty, +\\infty)$', '$(0, +\\infty)$']} correctAnswer={1} explanation="$f'(x) = 3x^2 - 3 = 3(x+1)(x-1)$。令 $f'(x) > 0$，得 $x < -1$ 或 $x > 1$。单调递增区间为 $(-\\infty, -1)$ 和 $(1, +\\infty)$。" difficulty="medium"  />

<PracticeProblem client:only="solid-js" question={"已知 $f(x)$ 是定义在 $\\mathbb{R}$ 上的奇函数，且当 $x > 0$ 时 $f(x) = x^2 + 1$，则 $f(-2)$ 的值为:"} options={['$5$', '$-5$', '$3$', '$-3$']} correctAnswer={1} explanation="由于 $f(x)$ 是奇函数，$f(-2) = -f(2)$。当 $x > 0$ 时 $f(x) = x^2 + 1$，所以 $f(2) = 4 + 1 = 5$。因此 $f(-2) = -5$。" difficulty="easy"  />

<PracticeProblem client:only="solid-js" question={"函数 $y = 2^x$ 与函数 $y = \\log_2 x$ 的图像关于哪条直线对称?"} options={['$y = x$', '$y = 0$', '$x = 0$', '$y = -x$']} correctAnswer={0} explanation="$y = 2^x$ 与 $y = \\log_2 x$ 互为反函数，反函数的图像关于直线 $y = x$ 对称。" difficulty="easy"  />

<PracticeProblem client:only="solid-js" question={"在 $\\triangle ABC$ 中，$a = 3$，$b = 4$，$C = 60^\\circ$，则 $c$ 的值为:"} options={['$\\sqrt{13}$', '$\\sqrt{37}$', '$5$', '$7$']} correctAnswer={0} explanation="由余弦定理：$c^2 = a^2 + b^2 - 2ab\\cos C = 9 + 16 - 2 \\times 3 \\times 4 \\times \\dfrac{1}{2} = 25 - 12 = 13$，故 $c = \\sqrt{13}$。" difficulty="medium"  />

## 概率与统计

<PracticeProblem client:only="solid-js" question={"从 1, 2, 3, 4, 5 五个数字中任取两个不同的数字，其和为偶数的概率为:"} options={['$\\dfrac{2}{5}$', '$\\dfrac{3}{5}$', '$\\dfrac{1}{2}$', '$\\dfrac{1}{5}$']} correctAnswer={0} explanation="总取法为 $\\binom{5}{2} = 10$ 种。和为偶数要求两个数字同奇或同偶：奇数对 $\\{1,3\\}, \\{1,5\\}, \\{3,5\\}$ 共 3 种；偶数对 $\\{2,4\\}$ 共 1 种。合计 4 种。概率为 $\\dfrac{4}{10} = \\dfrac{2}{5}$。" difficulty="medium"  />

<PracticeProblem client:only="solid-js" question={"某班有 50 名学生，其中女生 20 人。用分层抽样抽取 5 人，则应抽取女生人数为:"} options={['$2$', '$3$', '$4$', '$1$']} correctAnswer={0} explanation="分层抽样按比例分配。女生比例为 $\\dfrac{20}{50} = \\dfrac{2}{5}$，抽取 5 人中女生应为 $5 \\times \\dfrac{2}{5} = 2$ 人。" difficulty="easy"  />

## 微积分基础

<PracticeProblem client:only="solid-js" question={"$\\displaystyle\\lim_{x \\to 0} \\dfrac{\\sin 3x}{x}$ 的值为:"} options={['$3$', '$1$', '$0$', '不存在']} correctAnswer={0} explanation="利用重要极限 $\\displaystyle\\lim_{x \\to 0} \\dfrac{\\sin x}{x} = 1$，得 $\\displaystyle\\lim_{x \\to 0} \\dfrac{\\sin 3x}{x} = \\displaystyle\\lim_{x \\to 0} 3 \\cdot \\dfrac{\\sin 3x}{3x} = 3 \\times 1 = 3$。" difficulty="easy"  />

<PracticeProblem client:only="solid-js" question={"函数 $f(x) = x^3 - 12x + 1$ 的极大值为:"} options={['$8$', '$-8$', '$17$', '$-15$']} correctAnswer={2} explanation="$f'(x) = 3x^2 - 12 = 3(x+2)(x-2)$。令 $f'(x) = 0$ 得 $x = \\pm 2$。$f''(x) = 6x$，$f''(-2) = -12 < 0$，故 $x = -2$ 为极大值点。极大值 $f(-2) = -8 + 24 + 1 = 17$。" difficulty="medium"  />

<PracticeProblem client:only="solid-js" question={"$\\displaystyle\\int_0^1 (3x^2 + 2x) \\, dx$ 的值为:"} options={['$2$', '$3$', '$1$', '$4$']} correctAnswer={0} explanation="$\\displaystyle\\int_0^1 (3x^2 + 2x) \\, dx = \\left[x^3 + x^2\\right]_0^1 = (1 + 1) - 0 = 2$。" difficulty="easy"  />
