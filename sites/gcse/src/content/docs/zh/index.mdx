## Intuition

**A bilingual bridge:** This Chinese-language page provides the same comprehensive GCSE content but in simplified Chinese, making it accessible to Chinese-speaking students.

**Why it matters:** Language should never be a barrier to education. This page ensures all students can access high-quality study materials.

**The key insight:** Technical concepts transcend language — the underlying principles of mathematics, science, and technology are universal.

## Common Mistakes

**被动重读笔记而不是做练习题:** 被动重读会创造熟悉感但不会带来理解。限时做往年试卷能揭示你实际知道什么，而不是你以为你知道什么。做完题目后对照评分标准检查答案。

**忽视答题指令词:** "描述"、"解释"、"评估"和"比较"要求不同的回答。描述 means 说明发生了什么；解释 means 说明为什么。误读指令词会导致写出错误类型的答案，即使知识正确也会丢分。

**不复习公式和定义:** GCSE考试要求你从记忆中回忆特定的公式和定义。把这些留到最后会导致知识缺口。创建公式表并定期用闪卡和间隔重复来测试自己。
