## Intuition

Computer science is about solving problems systematically — breaking complex tasks into algorithms that machines can execute. Hardware provides the physical foundation (CPU, memory, storage), while software provides the instructions. Databases organise data efficiently, networks connect systems together, and algorithms determine how quickly problems get solved. Understanding time complexity (Big O notation) tells you whether your solution scales or collapses under load.

## Common Pitfalls

- **Binary/hex conversion errors**: Forgetting that hex is base-16 (digits 0-9, A-F) and mixing up the direction of conversion — practice with small numbers first.
- **Stack vs heap confusion**: The stack stores local variables and function calls (fast, limited size), while the heap stores dynamically allocated memory (slower, larger) — confusing the two leads to memory leaks or stack overflow.
- **SQL injection**: Building SQL queries by concatenating user input directly — always use parameterised queries to prevent attackers from injecting malicious SQL commands.
