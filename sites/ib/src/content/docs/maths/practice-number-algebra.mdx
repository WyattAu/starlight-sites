## Worked Examples

### Example 1: Complex Number Division

**Problem:** Simplify $\frac{3 + 2i}{1 - i}$.

**Solution:**
Step 1: Multiply numerator and denominator by the conjugate of the denominator:
$\frac{3 + 2i}{1 - i} \times \frac{1 + i}{1 + i}$

Step 2: Numerator: $(3 + 2i)(1 + i) = 3 + 3i + 2i + 2i^2 = 3 + 5i - 2 = 1 + 5i$

Step 3: Denominator: $(1 - i)(1 + i) = 1 - i^2 = 1 - (-1) = 2$

Step 4: Answer: $\frac{1 + 5i}{2} = \frac{1}{2} + \frac{5}{2}i$

**Key insight:** Always multiply by the conjugate to make the denominator real. The conjugate of $a + bi$ is $a - bi$.

---

### Example 2: Geometric Sequence

**Problem:** Find the sum of the first 6 terms of the geometric sequence 5, 15, 45, ...

**Solution:**
Step 1: First term $a = 5$, common ratio $r = \frac{15}{5} = 3$

Step 2: Sum formula: $S_n = a \frac{r^n - 1}{r - 1}$

Step 3: $S_6 = 5 \times \frac{3^6 - 1}{3 - 1} = 5 \times \frac{729 - 1}{2} = 5 \times \frac{728}{2} = 5 \times 364 = 1820$

**Key insight:** The geometric sum formula works for any $r \neq 1$. For $|r| < 1$, the sum to infinity is $S_\infty = \frac{a}{1 - r}$.

---

### Example 3: Proof by Induction

**Problem:** Prove that $\sum_{r=1}^{n} r = \frac{n(n+1)}{2}$ for all $n \in \mathbb{Z}^+$.

**Solution:**
Step 1 (Base case): $n = 1$: LHS $= 1$, RHS $= \frac{1(2)}{2} = 1$ ✓

Step 2 (Inductive hypothesis): Assume true for $n = k$: $\sum_{r=1}^{k} r = \frac{k(k+1)}{2}$

Step 3 (Inductive step): Show true for $n = k+1$:
$$\sum_{r=1}^{k+1} r = \sum_{r=1}^{k} r + (k+1) = \frac{k(k+1)}{2} + (k+1)$$
$$= \frac{k(k+1) + 2(k+1)}{2} = \frac{(k+1)(k+2)}{2}$$

This equals the formula with $n = k+1$. ✓

**Key insight:** In the inductive step, factor out $(k+1)$ first — it makes the algebra cleaner.

**Q26. The statement 'If n is even, then n² is even' has contrapositive:**

A. If n² is even, then n is even
B. If n is odd, then n² is odd
C. If n² is odd, then n is odd
D. If n² is even, then n is odd

<details>
<summary>Show answer — C</summary>

**Answer: C** — Contrapositive of 'If P then Q' is 'If not Q then not P'. Here: P = 'n is even', Q = 'n² is even'. Not Q = 'n² is odd', not P = 'n is odd'. So: "If n² is odd, then n is odd''.

</details>

**Q27. In mathematical induction, what is the base step used for?**

A. To verify the statement holds for the initial value
B. To prove the statement for all n
C. To find the general formula
D. To test the inductive hypothesis

<details>
<summary>Show answer — A</summary>

**Answer: A** — The base step verifies that the statement is true for the starting value (n = 1 in the standard formulation). This is essential because induction proves: if true for n = k, then true for n = k + 1. Without a base case, the chain of reasoning has no foundation."

</details>

**Q28. Prove by induction that 1 + 2 + 3 + ... + n = n(n+1)/2. What is the inductive step?**

A. Show true for n = 1 only
B. Assume true for n = k, then show 1+2+...+k+(k+1) = (k+1)(k+2)/2
C. Substitute n = k directly into the formula
D. Prove by contradiction instead

<details>
<summary>Show answer — B</summary>

**Answer: B** — Assume 1+2+...+k = k(k+1)/2 for some k ≥ 1. Then 1+2+...+k+(k+1) = k(k+1)/2 + (k+1) = (k+1)(k/2+1) = (k+1)(k+2)/2. This proves the formula for n = k+1, completing the inductive step."

</details>
