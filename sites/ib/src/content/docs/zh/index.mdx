# IB 学习笔记

针对 IB 国际文凭文凭课程的全面学习资料，涵盖数学、科学和人文科目。

## Intuition

**中文学习是通往中华文化的桥梁 — 语言承载着数千年历史、哲学和艺术的智慧:** 掌握中文不仅是学习语言，更是理解东方思维方式和文化价值观的钥匙

**Why it matters:** 中文是世界上使用人数最多的语言，学习中文为跨文化交流和理解中国社会打开大门

**The key insight:** 掌握中文不仅是学习语言，更是理解东方思维方式和文化价值观的钥匙


## Why This Matters

IB（国际文凭）课程是全球认可的高中课程体系，强调批判性思维、跨学科联系和国际视野。掌握这些科目的核心概念不仅帮助你通过考试，更为大学阶段的深入学习打下坚实基础。这些笔记提供系统化的复习材料，覆盖 IB 课程大纲的每个主题。

## Common Mistakes

**Assuming language affects concept difficulty:** Technical concepts are universal. The language of instruction doesn't change the underlying science or mathematics.

**Not using both English and Chinese resources:** Some concepts are better explained in one language. Use both to deepen understanding.

**Forgetting that IB exams are in English:** Even if you study in Chinese, practice answering in English to prepare for the actual exam format.
