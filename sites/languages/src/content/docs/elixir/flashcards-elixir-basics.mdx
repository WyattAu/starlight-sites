## Intuition

Elixir runs on the Erlang VM (BEAM), designed for building fault-tolerant, distributed systems. Everything is a function call — there are no loops, only recursion and higher-order functions like `Enum.map`. Pattern matching is pervasive: it's used for function dispatch, error handling (`case`/`with`), and data destructuring. OTP provides battle-tested building blocks (GenServer, Supervisor) that implement the "let it crash" philosophy — processes fail independently and supervisors restart them.

## Common Pitfalls

- **Pipe operator precedence**: The `|>` pipe operator has low precedence — expressions in the pipe chain can bind unexpectedly. Use parentheses for complex arguments.
- **Agent vs GenServer**: Using Agent for anything beyond simple state — Agent is a convenience wrapper; GenServer gives you full control over handle_call/handle_cast/handle_info.
- **Binary pattern matching**: Forgetting that `<<a, b::binary>>` matches a byte and the rest as binary — `b::binary` is required to capture remaining bytes, not just `b`.
