## Intuition

**Computer science is about solving problems systematically:** It combines logical thinking with practical skills to design algorithms, write programs, and build systems. The key is breaking complex problems into smaller, manageable pieces.

**Why it matters:** Digital literacy is essential in the modern world — understanding programming, data, and systems helps you make informed decisions about technology.

**The key insight:** Algorithms are not just for computers — they are step-by-step procedures for solving any problem, and choosing the right algorithm can mean the difference between a solution that takes seconds and one that takes years.

## Common Mistakes

**Confusing compilation with interpretation:** Compilation translates entire source code to machine code before execution. Interpretation translates and executes line by line. Some languages use both — compilation to bytecode then interpretation.

**Ignoring time complexity in sorting algorithms:** Bubble sort is O(n^2) and practically unusable for large datasets. Merge sort is O(n log n) and handles large datasets well. Choosing the wrong algorithm for the data size leads to unacceptable performance.

**Misunderstanding recursion limits:** Each recursive call adds a stack frame. Too many recursive calls cause stack overflow. Factorial(1000) overflows in most languages. Convert deep recursion to iteration or use tail-call optimisation where supported.
