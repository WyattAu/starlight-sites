## Intuition

Computer science is the study of computation — how to represent information, design algorithms, and build systems that solve problems efficiently. Hardware provides the physical substrate (CPU, RAM, storage), while software provides the instructions. Databases organise data for efficient retrieval, networks connect systems across distances, and algorithms determine how quickly (or slowly) problems get solved as input size grows.

## Common Pitfalls

- **Binary conversion mistakes**: Forgetting that binary is positional (powers of 2) — converting 1011₂ as 1+0+1+1 instead of 8+0+2+1 = 11₁₀.
- **Loop boundary errors**: Off-by-one errors (iterating one too many or too few times) are the most common programming bug — check whether loops should use `<` or `<=`.
- **SQL join confusion**: Mixing up INNER JOIN (only matching rows) with LEFT JOIN (all left rows + matching right rows) — the choice affects which rows appear in results.
