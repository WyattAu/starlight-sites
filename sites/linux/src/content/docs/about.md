## About Wyatt's Notes — Linux

Wyatt's Notes offers comprehensive study materials for Linux administration. These notes cover system administration, shell scripting, networking, security, and server management, building the skills needed to manage Linux systems in production environments.

### Why Trust These Resources?

These notes are created by **Wyatt**, an educator and content developer with expertise in Linux systems administration. Content follows a structured progression from basic commands through system configuration to advanced administration topics.

Materials emphasise the command-line proficiency and system understanding that professional Linux administrators need. Every concept includes practical examples and explains the underlying system mechanics, not just the commands.

### What You'll Find

- **System administration** covering users, permissions, and process management
- **Shell scripting** with Bash scripting and automation
- **Networking** covering configuration, firewalls, and troubleshooting
- **Security** with SELinux, auditing, and hardening
- **Server management** including systemd, services, and monitoring

### Credentials

Wyatt develops resources across Linux, networking, and security, providing the infrastructure perspective that enhances Linux materials. Content is informed by Linux documentation, industry certifications, and production server administration.
