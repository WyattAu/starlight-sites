### Additional Flashcard Topics

- **σ-Algebra**: a collection Σ of subsets of X closed under complements and countable unions. The Borel σ-algebra on ℝ is generated by open sets. σ-algebras provide a "safe" domain for defining measures — not all subsets can be measured.

- **Measure**: a function μ: Σ → [0,∞] satisfying μ(∅) = 0 and countable additivity: μ(∪Aₙ) = Σμ(Aₙ) for disjoint Aₙ. The Lebesgue measure extends length: μ([a,b]) = b-a. Probability is a measure with μ(X) = 1.

- **Lebesgue Integration**: for a non-negative measurable function f, ∫f dμ = sup\{∫s dμ : 0 ≤ s ≤ f, s simple\}. This sums function values over level sets rather than domain partitions, enabling powerful convergence theorems.

- **Monotone Convergence Theorem**: if 0 ≤ f₁ ≤ f₂ ≤ ... and fₙ → f pointwise, then ∫fₙ dμ → ∫f dμ. This allows passing limits under the integral sign for non-negative increasing sequences.

- **Dominated Convergence Theorem**: if fₙ → f pointwise and |fₙ| ≤ g with ∫g dμ < ∞, then ∫fₙ dμ → ∫f dμ. The dominating function g provides the "control" needed to interchange limit and integral.

- **Fubini-Tonelli Theorem**: for product measures, ∫∫ f dμ×ν = ∫(∫f dμ) dν = ∫(∫f dν) dμ, provided ∫∫|f| dμ×ν < ∞. Without the absolute integrability condition, iterated integrals can differ.

## Intuition

Measure theory generalises the concept of "size" — length, area, volume — to abstract sets. A σ-algebra is a collection of sets that is closed under complements and countable unions, providing a safe domain for defining measures. The Lebesgue measure extends length to "wild" sets (like the Cantor set) that have no classical length. Lebesgue integration sums function values over level sets rather than domain partitions, enabling powerful convergence theorems (Monotone, Dominated, Fatou) that fail for Riemann integrals. The key insight is that measure theory provides the rigorous foundation for probability, integration, and functional analysis.

## Common Pitfalls

- **Measurable ≠ Borel**: Not every subset of ℝ is Lebesgue measurable — Vitali sets require the Axiom of Choice to construct and are non-measurable. Don't assume all sets have a well-defined measure.
- **Almost everywhere**: Two functions can differ on a set of measure zero and still be "equal" in Lᵖ — integration ignores such differences, which can be counterintuitive.
- **Fubini-Tonelli conditions**: You can only swap the order of integration if the double integral of the absolute value is finite — without this condition, iterated integrals can differ.
- **Confusing complete with σ-finite**: a measure is σ-finite if the space is a countable union of finite-measure sets. σ-finiteness is needed for many theorems (e.g., Fubini-Tonelli) but is weaker than finiteness.
- **Forgetting that measures are countably additive**: μ(∪Aₙ) = Σμ(Aₙ) for disjoint Aₙ. Finite additivity (for finitely many sets) is weaker and does not imply countable additivity.
