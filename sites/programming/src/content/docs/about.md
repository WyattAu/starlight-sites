## About Wyatt's Notes — Programming

Wyatt's Notes offers comprehensive study materials for programming across multiple languages and paradigms. These notes cover C++ as the primary focus, with additional resources for Python, Java, and other major languages, building from fundamentals to advanced systems programming.

### Why Trust These Resources?

These notes are created by **Wyatt**, an educator and content developer with expertise in multiple programming languages and paradigms. Content emphasises hands-on coding, problem-solving, and the software engineering principles that distinguish professional developers.

Materials are structured to build practical skills progressively. Every concept includes worked code examples, common pitfalls, and the best practices that experienced developers rely on in production environments.

### What You'll Find

- **Language-specific notes** for C++, Python, Java, and more
- **Programming paradigms** covering procedural, object-oriented, and functional styles
- **Data structures and algorithms** implemented across multiple languages
- **Software engineering principles** including design patterns and testing

### Credentials

Wyatt develops resources across programming, computer science theory, and systems administration, providing the full-stack perspective that enhances programming materials. Content is informed by industry standards, open-source best practices, and academic CS curricula.
