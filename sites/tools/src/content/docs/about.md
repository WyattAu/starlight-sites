## About Wyatt's Notes — Tools

Wyatt's Notes provides comprehensive study materials for development tools. These notes cover version control, build systems, containerisation, CI/CD pipelines, and developer productivity tools, building the skills needed for efficient software development workflows.

### Why Trust These Resources?

These notes are created by **Wyatt**, an educator and content developer with expertise in software development toolchains. Content follows a structured progression from individual tool usage through workflow automation to infrastructure-as-code.

Materials emphasise the practical toolchain knowledge that distinguishes productive developers. Every concept includes practical examples and explains when and why to use each tool, not just how.

### What You'll Find

- **Version control** with Git workflows and branching strategies
- **Build tools** covering Make, CMake, Maven, and modern alternatives
- **Containerisation** with Docker and Kubernetes
- **CI/CD** covering GitHub Actions, Jenkins, and pipeline design
- **Developer tools** including linters, formatters, and debuggers

### Credentials

Wyatt develops resources across development tools, programming, and systems administration, providing the DevOps perspective that enhances tools materials. Content is informed by industry best practices, tool documentation, and production development workflows.
