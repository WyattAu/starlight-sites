## Intuition

**TrueNAS management is about balancing performance, capacity, and reliability:** Storage configuration involves trade-offs between redundancy (RAID level), performance (stripe width), and capacity (usable space).

**Why it matters:** Proper storage configuration prevents data loss and ensures consistent performance for users and applications.

**The key insight:** Regular monitoring and proactive maintenance — checking SMART data, verifying scrub results, and monitoring usage trends — prevents catastrophic failures.

## Common Mistakes

**Configuring SMB shares without proper permissions:** SMB uses Windows-style ACLs. Setting permissions incorrectly causes access denied errors or exposes data to unauthorized users. Test share access from multiple clients before going live.

**Using TrueNAS for VM storage without understanding IOPS:** ZFS volumes for VMs need sufficient IOPS. Small random reads/writes perform differently than sequential transfers. Use SSDs for VM storage and configure appropriate record sizes.

**Not configuring email alerts:** TrueNAS can email you about pool degradation, temperature warnings, and SMART alerts. Without email configuration, hardware failures may go unnoticed until its too late.
