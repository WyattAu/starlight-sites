## Memory Management

<PracticeProblem client:only="solid-js" question={"What is false sharing in the context of CPU caches?"} options={'Different variables on the same cache line modified by different cores, triggering coherence traffic', 'Two threads sharing the same variable', 'A cache line being invalidated by the OS', 'Two cores accessing the same memory address'} correctAnswer={0} explanation="False sharing occurs when unrelated variables share a cache line and are modified by different cores. Each write triggers a coherence round-trip, effectively serializing access and devastating multi-threaded performance." difficulty="medium"  />

It must be written back when evicted." difficulty="medium"  />

## I/O Optimization

<PracticeProblem client:only="solid-js" question={"What is the primary advantage of using NVMe over SATA for storage?"} options={'Much lower latency and higher IOPS due to a more efficient protocol', 'Higher storage capacity', 'Lower cost per GB', 'Better data integrity'} correctAnswer={0} explanation="NVMe uses a leaner protocol with fewer abstraction layers and hardware-level queuing (up to 64K queues), dramatically reducing latency and increasing IOPS compared to SATA." difficulty="easy"  />

## Network Tuning

<PracticeProblem client:only="solid-js" question={"What is the purpose of TCP_NODELAY (disabling Nagle's algorithm)?"} options={'Sends small packets immediately without waiting to fill a full segment', 'Increases the TCP window size', 'Enables TCP segmentation offload', 'Reduces the number of retransmissions'} correctAnswer={0} explanation="Nagle's algorithm buffers small packets to reduce overhead. Disabling it (TCP_NODELAY) sends small packets immediately, reducing latency for interactive applications at the cost of slightly more overhead." difficulty="medium"  />

<PracticeProblem client:only="solid-js" question={"What is the benefit of enabling receive packet steering (RPS) on a multi-core system?"} options={'Distributes packet processing across multiple CPU cores', 'Increases the network interface card speed', 'Reduces memory usage', 'Enables hardware checksumming'} correctAnswer={0} explanation="RPS distributes incoming packet processing across multiple CPU cores, preventing a single core from becoming a bottleneck. It is especially useful when the NIC does not support RSS (Receive Side Scaling)." difficulty="medium"  />

<PracticeProblem client:only="solid-js" question={"What is the typical effect of increasing the TCP receive buffer size?"} options={'Higher throughput for high-bandwidth, high-latency connections', 'Lower latency for all connections', 'Reduced CPU usage', 'Smaller packet sizes'} correctAnswer={0} explanation="Larger TCP buffers allow more data in flight, which is essential for filling the bandwidth-delay product on high-bandwidth, high-latency links (e.g., 10 Gbps over 100 ms RTT)." difficulty="medium"  />
