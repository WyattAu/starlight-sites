PracticeProblem SolidJS Tested

Adaptive multiple-choice practice with keyboard navigation (arrow keys + Enter), difficulty badges, and results dialog. Supports single question or array of questions.

Render via Astro page: src/content/docs/preview/practice-problem.mdx

Requires Astro dev server for full interactive preview.

FlashcardDeck SolidJS Tested

SM-2 spaced repetition flashcards with keyboard shortcuts (Space to flip, 1-4 to rate), mastery tracking, streak counting, import/export, and prefers-reduced-motion support.

Sub-modules: flashcard/sm2.ts, flashcard/storage.ts, flashcard/constants.ts

DiagnosticTest SolidJS Tested

Adaptive diagnostic assessment. Dynamically selects questions based on user performance, targeting weak topics. Tracks per-topic scores and computes strengths/weaknesses.

Self-contained component with adaptive question selection algorithm.

DesmosGraph SolidJS

Embeds Desmos graphing calculator. Two modes: expression-based (programmatic with auto-detected sliders) or iframe URL. Loads Desmos API dynamically.

Requires Desmos API script load. Test with: <DesmosGraph expressions={["y=x^2"]} />

PhetSimulation SolidJS

Embeds PhET Colorado interactive simulations via sandboxed iframe with responsive aspect ratio, lazy loading, and strict referrer policy.

Test with: <PhetSimulation simulationId="forces-and-motion-basics" />
